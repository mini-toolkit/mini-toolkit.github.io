# Mini Toolkit

🌐 **Live Site:** https://mini-toolkit.github.io/

A collection of **30 fast, privacy-friendly browser utilities** that run 100% locally in your browser using JavaScript — no server uploads required.

## Features
- **30 Independent Web Tools**: Each tool has its own clean URL and works directly in the browser.
- **9 Languages Supported**: English, 中文, हिन्दी, Español, Français, 日本語, Português, Deutsch, 한국어.
- **Built-in Guides**: Usage guides for all 30 tools available in the Blog tab.
